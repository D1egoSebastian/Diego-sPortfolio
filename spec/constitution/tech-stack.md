# Tech Stack

Basado en el template [D1egoSebastian/D1egoSebastian.github.io](https://github.com/D1egoSebastian/D1egoSebastian.github.io) (fork de MarcusHoltz/astro-portfolio-theme).

| Capa | Tecnología |
|---|---|
| Framework | Astro 5+ |
| UI | Tailwind CSS v4 |
| Lenguaje | TypeScript |
| Package manager | pnpm 11+ |
| Node.js | 24+ |
| Linter | ESLint (flat config) |
| Formatter | Prettier |
| Type checker | Astro Check (TypeScript strict) |
| Hosting | GitHub Pages (deploy via GitHub Actions) |
| Contacto | Web3Forms (API key) |
| Iconos | Iconify (descarga local en build time) |
