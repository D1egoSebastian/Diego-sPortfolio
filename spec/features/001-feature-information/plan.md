# Plan: Información Personal

## Objetivo
Adaptar los archivos de datos del template Astro Portfolio Theme con la información personal del usuario: nombre, bio, contacto, foto, certificaciones, secciones del sitio.

## Archivos a modificar

| Archivo destino | Propósito |
|---|---|
| `src/data/personal.json` | Nombre, título, bio, contacto, redes, foto, educación |
| `src/data/site.json` | Título del sitio, SEO, clave Web3Forms, navegación externa |
| `src/data/menu.json` | Etiquetas de navegación del menú lateral |
| `public/images/personal/portrait.png` | Foto de perfil |

## Dependencias
- Template base clonado/configurado (Fase 1)
