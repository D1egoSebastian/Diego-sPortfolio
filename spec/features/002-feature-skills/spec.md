# Fase 2: Herramientas / Skills

- **Descripción:** Proporcionar al agente toda la información de las herramientas que puedo manejar.

## Stack Técnico

### Principal
C# · ASP.NET Core · Entity Framework · REST APIs

### Bases de Datos
MySQL · MongoDB · SQL Queries y diseño de esquemas

### Herramientas
Git / GitHub · Postman · Visual Studio · Service Desk · Paquete Office

### Secundario
Node.js · Express · HTML · CSS · JavaScript

### IA
OpenCode (terminal AI)

## Criterios de Aceptación

- [ ] Las 4 tarjetas de Expertise se muestran con iconos y descripciones coherentes
- [ ] Las categorías de Skills se muestran correctamente agrupadas
- [ ] Cada skill tiene un icono representativo (Iconify)
- [ ] La IA/herramientas de terminal aparecen en alguna categoría

## Casos Borde

- Si un icono de Iconify no puede descargarse, debe omitirse sin romper el layout
- Skills sin icono deben mostrar un placeholder o el nombre solamente
